# Start with a system runbook

The underlying native systems have been tested on GCP using the experiment
runbooks. Open a public runbook below and follow its commands in order:

- [RAD](https://github.com/Kibnelson/rad_tyg1/blob/rad/RUNBOOK.md)
- [Milvus](https://github.com/Kibnelson/rad_tyg1/blob/milvus/RUNBOOK.md)
- [SIMD-DPK](https://github.com/Kibnelson/rad_tyg1/blob/simd_dpk/RUNBOOK.md)
- [Faiss(Jaccard)](https://github.com/Kibnelson/rad_tyg1/blob/faiss_jaccard/RUNBOOK.md)

Each runbook includes setup, the test command, what a successful result looks
like, and a larger-data example. It clones the correct branch into its own folder.
You do not need to clone `main` first. Shared download instructions are in
[DATASETS.md](DATASETS.md).
